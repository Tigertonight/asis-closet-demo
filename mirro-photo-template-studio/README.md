# Mirro Photo Template Studio

一个完全独立于 Mirro 原目录的 PC Web 工具，用于导入 Mirro 拍摄原图、套用提供的 LUT 效果链，并排版导出图片模板。

## 运行

```bash
npm install
npm run dev
```

访问终端显示的本地地址。所有图片处理均在浏览器本地完成，不会上传。

## 已实现

- 点击选择或直接拖拽上传 JPG、PNG、WEBP 原图
- 解析并应用附件中的 512×512 双 LUT（肤色 / 背景）
- 支持导入自定义 8×8 PNG LUT 或 `.cube` LUT
- 暗角、柔化、细噪、明暗和 LUT 强度实时调整
- 四种素材版式：酒红/银灰硬边框、酒红/银灰蕾丝框；直接使用 `02_MATERIAL_SINGLE.zip` 原始透明 PNG 覆盖层
- 外层批次工作台：批量导入、多选、统一模板、逐张进度与完成/失败状态
- 将选中的已完成成片打包为 ZIP 批量导出
- 鼠标拖动构图、缩放、成片/原图对比
- 1080px 高清 PNG 本地导出

## 原配置映射

附件原始顺序为：暗角 → 肤色分割双 LUT → 高斯模糊 → 细噪。Web 工具在交互语义上复刻参数默认值，并使用轻量肤色启发式替代原 SDK 才能提供的人像分割 mask。生产接入 Mirro 人像分割结果后，可把 mask 直接传入 LUT 混合步骤以获得逐像素一致性。
