# Selfit 人格测试 10 用户模拟对拍报告

生成日期：2026-08-28

## 一、测试目的

使用 10 组完整用户答卷，分别执行：

- 后端 Python 算法：`app/selfit_persona.py`
- 前端 mock JavaScript 算法：`app/static/selfit/selfit-persona.js`

对比主人格、次人格、主人格距离、次人格距离和置信度是否一致。

## 二、选项说明

三个滑杆均为 0–100：

- `shape`：0=硬朗锐利，100=柔和温柔
- `energy`：0=简约克制，100=精致繁复
- `trend`：0=经典耐看，100=时髦先锋

VIBE 题目：

- Q1 `occasion`：A=少什么？能出门就行；B=加一个配饰，给今天留点尊严；C=全部脱掉，我要重新做人
- Q2 `wardrobe`：A=收藏夹和衣柜基本是同一个人；B=收藏夹在巴黎，衣柜在赶早八；C=每张收藏图都很好看，但互相不认识
- Q3 `expression`：A=日系自然舒适；B=韩系精致统一；C=欧美修身气场；D=中式东方含蓄；E=法式衬衫牛仔红唇

## 五、结论

- 10/10 组主人格一致。
- 10/10 组次人格一致。
- 10/10 组主人格距离与次人格距离一致。
- 10/10 组置信度一致；后端保留 4 位小数，前端保留 JavaScript 原始浮点精度。
- 前端 mock 不返回后端的 `confidence_tier` 字段，这是输出契约差异，不影响人格选择。
- U07、U08、U10 在两端都正确触发了“轻亚”二次推导。

本轮结论：在这 10 组覆盖极简、冷感、老钱、松弛、甜感、侘寂、吸睛、轻亚、胶片和混搭风格的样本中，前端 mock 与后端核心分型结果完全一致。
