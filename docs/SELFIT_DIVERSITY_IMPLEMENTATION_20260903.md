# 推荐去同质化实施与验证

日期：2026-09-03。范围：推荐排序、跨页曝光约束、款式家族基础设施、独立人格复核交付包。不改人格分型算法，不覆盖原始单品/穿搭资产，不自动发布或删除内容。

## 已生效

1. 主配方与替换版本保留真实父配方关联，同一父配方的两次曝光位置差至少为 8。首屏 6 套不会同时出现同一配方的主版和替换版。
2. 任意连续 10 套中，同一上装、外套、裤装、半裙、连衣装 ID 最多出现 2 次。不是只限制 hero 标签，所有主服装均参与约束。
3. 同样的窗口也限制已复核款式家族最多出现 2 次。包、鞋等不占主服装限额；不会因为颜色相近就过滤人格标志色。
4. 浏览器继续传递有序已曝光 ID，后端用上页末尾 9 套参与本页计算。分数变化不会重置跨页窗口；延后候选在每次选中后重新评估。
5. 当剩余内容均违反约束时返回较短页面并停止滚动，不用重复内容补足。页面提示“相似的穿搭已为你收起，可以换一批看看。”
6. 测试模式仍只读取所选人格发布池，不读取私人衣橱或反馈。正式模式保留原评分和个人作品优先份额，但个人作品也必须满足重复约束。

约束范围是当前推荐列表 / 本轮滚动会话。主动“换一批”或重新进入页面会重建列表；本次没有实现跨会话长期曝光历史。`exclude_outfit_ids` 必须保持实际展示顺序。

实现入口：`app/recommendation_diversity.py`；目录适配与 API 接入：`app/closet.py`。响应保留原字段，新增 `diversity` 诊断信息，消费者页面不展示技术参数。

## 款式家族：已建机制，未冒充全量审完

注册表在非静态目录 `app/data/garment-style-families.v1.json`。每组包含类别、成员指纹、视觉审核者、依据和决策原因。任何成员元数据变化会让该组失效；注册表缺失或损坏时退回单件家族，主单品 ID 限制仍有效。

当前确认 3 组 / 6 件，剩余 594 件按独立家族处理，即 597 个有效家族。这里的确认来自已有**非盲视觉审计**，不是独立人格审核。

| 家族 | 两件单品 | 视觉依据 |
|---|---|---|
| 藏蓝腰带百褶裙 | HEIR skirt 0435 / 0579 | 褶裥、腰部、长度高度相似 |
| 米色翻领卷袖衬衫 | EASE top 0324 / 0564 | 领型、口袋、袖长、轮廓高度相似 |
| 浅蓝高腰长裤 | ICED bottom 0402 / 0418 | 颜色和高腰长裤轮廓相近，缩略图差异小 |

原审计的 443 对机器近似候选仅是候选队列，不能整体自动归组。需继续按领型、袖型、长度、体积、腰线、结构、图案、材质观感、颜色逐对复核；未知字段保留未知，不能拿生产提示词当实际视觉标签。家族不会改变原资产身份或将资产下架。

## 独立人格复核：已准备，待实际审核

`scripts/selfit_persona_review.py` 生成 160 套样本：每人格 10 套，入门 4 / 典型 4 / 实验 2，160 个不同父配方，优先分散主单品。不根据既有评分挑选“最好看的”样本。

交给独立审核者：

`docs/audits/20260903-independent-persona-review/reviewer.zip`

包内包含 160 张去源文件名的穿搭图、8 张匿名联系表、统一的 16 人格定义、待填答案和说明。**不要同时给审核者 `examiner-key.json`**。该答案映射保存在包外；不在 `/static/` 下提供任何复核材料。

当前：已回收审核 0 / 160；Top-1、Top-2 均未知。目标分别为 70% / 90%，不是已取得的成绩。

回收后运行：

```bash
.venv/bin/python scripts/selfit_persona_review.py grade \
  docs/audits/20260903-independent-persona-review/examiner-key.json \
  /absolute/path/to/completed-answers.json \
  /absolute/path/to/new-review-result.json
```

工具要求独立性与未见标签声明、审核者标识、每套不同的 Top-1 / Top-2、视觉理由、问题列表及 accept / reject / uncertain 决策；拒绝缺失/重复答案、错包、过期穿搭/单品记录与过期封面。它只能记录独立性声明，不能认证真实审核者身份。

成绩按人格和全体输出，逐套保留问题与记录指纹。即使达标也不自动批准发布池；拒绝或不确定样本需人工处置，必要时调整人格归属、补标或下架。160 套抽样不代表 1,169 套全量通过。
