# 叠穿预览与反馈控件修复（2026-09-03）

## 设计与实现

- 外套左侧、内搭与下装中列、鞋包固定右侧；各槽位互不覆盖。
- 先裁透明留白，再等比放入安全区域；内搭底部与下装顶部相距 24px（1200×1500 画布）。
- 鞋子上移，给详情右下角的模特缩略图留出空间。
- 个人搭配保留独立 `outer` 槽位，外套不再被当成重复上衣或配饰。
- 详情反馈沿用现有品牌颜色、线性图标，改为点赞/点踩两个 44×44px 控件；带可访问名称、选中态、键盘焦点和提交中保护。移除此处“我穿过”，其他穿着记录能力不变。
- 仅反馈保存成功后显示成功提示与选中态；点踩保留原因选择。

## 资产范围

`scripts/build_selfit_layered_previews.py` 已重建 192 套叠穿预览。
结果写入 `app/static/selfit/assets/content_v2/layouts/layered-side-by-side-v1/`，并保留逐图布局报告。

原始单品、原始穿搭图、已发布池 JSON、配方与审核决定均不改动。
App 的 V2 适配层只优先选择存在的新版预览；缺失时回退原图，不在列表请求中现场生成图片。
新增生产配方的渲染脚本也复用相同叠穿布局。
