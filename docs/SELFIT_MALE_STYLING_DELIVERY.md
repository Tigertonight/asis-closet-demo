## 处理与验收规则

22 张原有透明 PNG 原样保留；其余 79 张使用已有本地 BiRefNet 模型，以两个工作进程并行处理，每张分别处理原图与镜像预测，再取保守并集。保留原始尺寸和 RGB，不按白色全局删除像素。

逐张对照原图、棋盘背景和深色背景检查衣服、配饰边缘与高光。局部修正另存文件，并记录自动结果哈希和区域，避免修改原图。本批有四张局部修正：EASE「亨利针织」和 WABI「做旧针织」的透明眼镜清除镜片内残留白底；WABI「亚麻长袍」的围巾清除颈部空洞白底，黑色破坏肌理长上衣清除经目检确认的封闭镂空白底。修正限定在对应空洞内，保留镜框、镜腿、高光和衣物纤维，不对其他白色单品套用颜色阈值。

描述根据原穿搭与全部单品图一起核对，区分可见事实和无法确认的信息。部分 EDGE 印花、衣长及 WABI/MUTE 帽子图案与穿搭原图存在差异，描述中保留差异，不把缺少的配件假设成已有单品。保留源 JSON 的穿法与配对；按其 `layer_order` 稳定排序生成内外层次，原顺序另存到 `source_revision`。

`scripts/register_male_styling_delivery.py --batch outputs/male-delivery/20260910 --check-source` 可先检查源目录。正式导入去掉 `--check-source`，必须通过以下检查：

1. 四个人格各四套，117 张原图全部有明确引用，无重名绑定或缺失配对。
2. 101 张最终 PNG 为真实 RGBA，尺寸及 RGB 与源图一致，哈希与处理记录一致。
3. 每张最终 PNG 都有绑定其哈希的目检通过记录。
4. 原图、结果及局部修正已上传既有七牛桶，远端回读的字节、大小和对象位置匹配。
5. 旧目录未被并发修改；保留备份后，最后写入业务拆款清单。

重复执行已完成的导入会拒绝，避免重复追加。后续修改已有男性素材需明确修订，不重新运行原始 80 套整库覆盖脚本。

## 页面与试穿

灵感库仍有四个场景／趋势合集与 16 个人格合集。对应人格内增加“男生穿搭”分组，原封面与前三张预览保持原标准版，微胖组独立保留，空分组隐藏。首页六篇随机笔记按账号性别选择；显式打开的穿搭在刷新时仍可固定在首位。

男性报告笔记通过原接口精确解析，例如：

`GET /selfit/try-on/report-outfits?persona=ease&template_id=ease-male&note_ids=outfits-01,outfits-02,outfits-03,outfits-04`

带有旧版女性图片 ID 的请求不会静默替换成男性素材。卡片详情、收藏与试穿沿用现有结构化套装流程，传递原穿搭参考、全部单品和穿法层次。2026-09-11 已补齐默认男模特的 16 张预设试穿图，详见下节。

拆款导入不改变人格分型算法、默认报告选择规则或原白 T 的 66 条固定匹配。2026-09-11 已在白 T JSON 的独立 `male` 分区追加 15 条男性固定匹配，并按账号性别选取；原女款候选池快照保持不变。分组和使用规则见 [白 T 固定匹配](WHITE_TEE_MATCHES.md)。

测试覆盖男性模板隔离、目录完整性、引用与配对、已有封面保持、按性别抽样，以及前端分组、现有报告与试穿数据链路。73 项 Python 测试和 12 项前端测试通过；16 套生成参数覆盖全部 101 个单品，117 张最终图片的同源接口读取与哈希校验通过，未调用付费生图。393px、430px 手机布局及 1440px 桌面居中布局已目检，独立浏览器中的编辑器无脚本或资源加载错误。实际完成记录见本地批次的 `final-validation.json` 和 `qa-validation.json`。本地接入及 OSS 上传不等于服务器发布。

## 男模特试穿预设（2026-09-11）

覆盖 `male_standard_1` 默认男模特 × 四个人格各四套，共 16 张。模特照片来自当前主数据的 `image_asset_id`，每张输出为 1792 × 2400，沿用原照片画幅。其他男模特和用户照片不复用这一组图片。

通过内置 `image_gen` 执行现有的“服装、配饰”两阶段请求。保留每次原生输出、请求哈希、原图哈希、画幅归一化记录和失败重试；默认男模特原图中的脸面积较小，通用检测器会误选胸口，本批仅对这张经过哈希校验的原图使用人工确认、三个检测器交叉验证的面部区域。原有面部／背景差异阈值不变。局部画幅取整误差仅接受 0.2% 以内，人物比例和完整画幅仍需目检。

16 张通过几何检查和逐张目检后，上传既有七牛桶 `selfit/tryon-examples/male-20260910/`，远端回读 SHA-256 全部一致。`app/data/tryon-examples.v1.json` 追加 16 条记录，原有 240 条记录逐条保持不变；原有失败与阻塞记录不会被改成成功。新增 `inputAssetIds` 约束，单品素材变更后会回到正常生成流程。

佩戴方式有两处明确调整：WABI-01 的墨镜放在帽冠；WABI-04 的墨镜挂领口、围巾改为绕颈垂下，以保留面部并避免遮挡检查失败。全部单品仍保留。部分 EDGE 印花及布料纹理是生成近似，不作为原素材文字或材质的像素级复刻。

本地批次目录：`outputs/tryon-examples/male-20260910/`。每套含 `job.json`、`result.png`、`visual-review.json`、`upload.json` 及生成阶段原始记录。操作入口为 `scripts/batch_male_tryon_presets.py`；`verify` 在上传前校验完整 16 套及全部输入／输出证据，`publish` 只追加本批，不覆盖原女性预设。图片二进制与过程文件均留在 Git 忽略目录。

接入验证：16 套真实接口均命中预设、不启动生图 worker、正常写入试穿历史，同源图片路由逐张通过哈希检查。隔离测试账号的浏览器实测 loading 约 3.19 秒；若图片尚未解码完成会继续等待。试穿前后镜框高度一致。393px、430px 手机与 1440px 桌面居中展示通过目检，无页面横向溢出、遮挡按钮、损坏资源或脚本错误。验证记录为 `runtime-validation.json`、`browser-validation.json`；代码回归覆盖模型照片、完整单品匹配、历史记录、3 秒等待及失败恢复。本批已本地接入并上传 OSS，尚未发布服务器代码。
