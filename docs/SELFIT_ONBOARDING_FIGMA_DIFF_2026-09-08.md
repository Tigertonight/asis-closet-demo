# Onboarding：Figma 差异与本次修改

对照范围：从启动、登录到 intro → 信息选择 → 上传照片 → like → vibe → 生成 → 报告与分享。信息选择在照片之前，是用户对本次流程的明确调整。修改位于主站的 `app/static/selfit/`，不是 `/wearwow/demo`。

- [当前 onboarding 分组](https://www.figma.com/design/7WvSROZhohAyvpEMfxZ3Dd/selfit?node-id=1079-3828)：`onboarding+mirror` 页面，分组尺寸 `6734 × 5573`，移动端基准 `393 × 852`。
- Intro 分离 / 叠合态：`1079:5454` / `1079:5505`。
- 问卷未完成 / 完成态：`1079:5867` / [1079:5954](https://www.figma.com/design/7WvSROZhohAyvpEMfxZ3Dd/selfit?node-id=1079-5954)。
- 加载序列：`1079:6109`、`1079:6157`、`1079:6203`、`1079:6251`。
- [当前报告](https://www.figma.com/design/7WvSROZhohAyvpEMfxZ3Dd/selfit?node-id=1079-6764)：`1079:6764`。同组内降低透明度的旧报告不作为本次目标。

Figma MCP 受当前 View seat 配额限制，本次通过 Figma 浏览器画布及属性栏核对。复用项目已导出的品牌、蕾丝卡片、照片引导和加载素材；本次没有获得新的二进制导出，也不宣称整份文件逐像素一致。

## 已完成的差异修改

| 页面 / 状态 | 修改前 | 修改后 |
|---|---|---|
| Intro 按钮 | 基准画面 CTA 顶部为 `y=760`，比设计低 24px | 恢复到 `(40,736)`，尺寸 `313 × 44` |
| Suit / like 标题 | 共享导航移出文档流后，标题仍沿用旧间距，整体上移 46px | 与 manual / vibe 对齐，标题在基准画面 `y=157` |
| Suit 照片反馈 | 长错误文本不换行；较矮窗口中可能与底部入口争抢空间 | 提示可换行，内容独立滚动，跳过入口和下一步保持可见 |
| 照片重选 / 重试 | 同一文件可能不再触发选择事件；旧请求可能覆盖新照片状态 | 支持同一文件重试、取消选择保留原图、旧校验失效、新照片重新校验 |
| 信息与照片顺序 | 从 intro 先进入照片页，手动填写是另一条路径 | 按用户要求改为信息选择 → 上传照片 → like；返回按相反顺序，保留选择和照片 |
| Like 小屏布局 | 下一步可能随内容滚出窗口 | 内容区滚动、CTA 固定；最后一组选色可以完整滚入操作区 |
| Like 可访问性 | 滑块与色板缺少完整名称 / 状态 | 三个滑块、六组色板补充语义名称和选中态，增加键盘焦点样式 |
| 步骤条 | 只有视觉上的当前步骤 | 同步 `aria-current="step"`，辅助技术可识别进度 |
| Vibe 文案 | 标题为“几个问题…”；未完成也显示生成文案 | 标题为“最后一步，了解你想表达的”；未完成显示禁用的“下一步”，答完三题显示“生成风格报告” |
| 报告动作 | 首屏隐藏，滚到穿搭区域后才出现 | 有效报告首屏即显示“返回重测 / 保存并分享”；公开分享页继续隐藏本人操作 |
| 较矮桌面窗口 | 固定 852px 高度，底部可能超出浏览器 | 使用页面已有的实际可见高度缩短外框，表单和分享层内部滚动 |
| 静态资源缓存 | 已打开页面可能仍复用旧样式 | 更新 CSS / JS 资源版本，实际本地主站重新加载后确认新布局生效 |

## 核对后保留的部分

- 启动页、品牌素材、intro 蕾丝卡片叠合动画、手动选项、三条偏好轴、六组色板、三道问卷和四段加载叙事已具备对应结构，继续复用。
- 登录保留现有主站的手机号直接登录。Figma 展示验证码流程，但本次不改变认证能力、短信发送或邀请码开放策略。
- 保留真实的 16 类人格、后端算法及报告素材库。设计中的 LACE 是示意报告，不能因此替换当前计算结果或更改算法口径。
- 报告保留网页上的返回导航，方便返回问卷修改答案。完整报告继续使用现有动态数据、推荐来源和长页结构。
- 分享保留可用的“分享给朋友（复制链接） / 保存图片”及三张卡片轮播。Figma 中小红书、微信和朋友圈的原生渠道不伪装成网页已接入的功能。
