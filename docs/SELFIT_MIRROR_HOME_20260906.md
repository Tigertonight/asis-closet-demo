# 试衣镜首页改版

## 交付链路

Onboarding 报告完成 → 试衣镜首页 → 人格推荐穿搭 → 上传本人照片或使用示例模特 → 确认试穿。

- 完成测试及已有报告用户登录后进入 `/selfit/try-on`。
- 保留原试衣镜的画面、自由搭配画布、单品选择条及「试衣镜 / 衣帽间 / 灵感库」装饰性底部导航。取消的是旧主 App 及其底部 tab，不是试衣镜自身的导航；旧 `/wearwow/demo` 链接跳转到新页面并保留穿搭详情 ID。
- 模特使用 `/selfit/try-on/models` 主数据。Onboarding 带照片进入时选择本人照片；无照片时显示示例标识、上传入口，首次试穿提示上传或继续使用示例。
- 灵感库使用账号人格推荐及系统公开内容，不读取个人搭配作为候选，接口失败不以衣帽间补位。
- 个人衣帽间只显示上传/收藏单品、收藏套装及包含个人单品的搭配。试穿系统套装所需的内部拷贝不代表用户拥有该衣服。
- 单品可生成搭配、直接试穿或自由搭配。生成搭配复用已发布推荐组合，保留用户单品并替换同部位衣服；最多生成 3 套，没有可用组合时提供重试和单品试穿。
- 穿搭详情、收藏与试穿均留在试衣镜内；首页提供读取本人完整风格报告的入口。

## 验证

- 自动化：个人衣帽间初始为空；试穿拷贝不成为拥有数据；收藏/取消收藏往返；上传单品生成搭配后仍保留原单品；跨用户不可访问；灵感推荐不读取个人搭配；旧详情链接兼容；既有模特主数据、试穿保存测试。
- 浏览器：当前账号的系统推荐与个人空衣橱分离；收藏进入衣帽间，取消收藏恢复；详情不跳回旧 App；主数据 6 位模特可见；风格报告可打开并返回试衣镜。
- 响应式：400px、431px、1440px 检查，无页面横向溢出；桌面居中；已检查页面无损坏图片和控制台错误。
- 本轮未调用外部模型重新生成试穿图；真实图像生成沿用既有任务接口，需要结合实际照片继续体验验收。
