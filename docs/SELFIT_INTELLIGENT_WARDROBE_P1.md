# selfit 智能衣橱 P1 产品与交互方案

## 目标

让“拆款 → 入柜 → 智能搭配 → 试穿 → 反馈”形成可学习、可修正、可解释的闭环。用户主要判断“是否适合我”，算法和任务细节不在主界面暴露。

## 1. 推荐反馈闭环

- 行为信号：曝光、喜欢、不喜欢、收藏、试穿、保存、穿过。
- 不喜欢原因：颜色、版型、场景、太正式、太复杂、重复推荐。
- 排序原则：人格与推荐色是基础层；收藏、喜欢、试穿和保存增强个人偏好；不喜欢、近期穿过、洗护中降低排序。
- 情境信号：季节、天气、当前场景、衣物可用状态。
- 解释文案只输出用户可理解的一个主要理由，如“符合你这次的穿衣场景”“衣橱常搭”“配色协调”。

## 2. 搭配器完整度

- 结构优先于偏好：选上衣后先推下装，选下装后先推上衣；主搭配完整后再推鞋、包和配饰。
- 冲突检查：重复下装、重复鞋包、连衣装与上下装冲突。
- 叠穿例外：被标记为外套、大衣、西装、开衫的上装可与内搭并存。
- 状态反馈：“先选一件主服装”“上衣已选，接下来优先推荐下装”“基础穿搭已完整，再加一双鞋”。
- 完整性、季节、场景、配色复杂度和洗护状态作为保存/试穿前检查。

## 3. 拆款结果校正

- 单件修正：左右旋转、自动裁掉多余留白、边缘清理。
- 结果结构：可将一件拆为两个片段，或将多个片段合并为一件单品。
- 入柜前检查：重复单品提示，颜色/材质/季节/场景标签预览，品类修正，批量勾选确认。
- 可用性分级：“可试穿”与“仅可搭配”。后者仍保留在搭配与参考图中，但不作为试穿替换对象。

## 视觉原则

- 延续 selfit 暖白画布、酒红核心行动、白色软卡片和图片优先的视觉语言。
- 状态提示使用轻量圆点和文案，不使用深色警告面板或技术术语。
- 高频修正为次级按钮，“完成入柜”和“生成试穿图”保留主 CTA 层级。

## 验收标准

- 393–430px 宽度无水平溢出、文字重叠和裁切按钮。
- 搭配完整度提示在候选列表上方可见，不被压缩。
- 选中上衣后，第一组候选必须为下装；主搭配完整后操作按钮可用。
- 反馈事件幂等，不会因重复点击累加。
- 标记为“仅可搭配”的单品不进入试穿替换列表，仍保留在整体风格参考中。
