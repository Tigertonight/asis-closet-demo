# 推荐人格测试模式

## 使用

- 在底部导航连续点击“我的”5次（5秒内）进入，弹出16人格选择器。
- 选择人格后跳转推荐页，重新请求该人格的穿搭推荐。
- 推荐页和“我的”顶部显示测试模式提示，可随时再次切换。
- 再连续点击“我的”5次退出，恢复原推荐人格。点击其他导航会重置未完成的连击。
- 同一标签页刷新保留测试状态；按用户 ID 隔离，只在 sessionStorage 保存开关和测试人格 ID，退出登录时清除。

## 边界

测试模式不写真实风格报告、人格缓存或 URL 中的正式人格。报告页、个人颜色和试穿模特不因测试切换而改变。

推荐继续调用 `/closet/recommendations/outfits`，传入测试人格完整模板及 `context.persona_preview: true`。预览忽略历史推荐反馈与最近穿着事件，测试曝光/点赞/点踩不落库，穿搭收藏在测试模式中不写入。

此功能只切换推荐人格，不是沙箱账号；衣橱编辑、上传、真实试穿等原有功能仍属于当前账号。

并发请求使用递增序号，仅最新请求能更新列表。切换时清空旧推荐并展示加载态；失败可重试，不把上一人格的结果放在新标签下。

## 验证

- 自动化覆盖四次不触发、第五次触发、再次五次退出、超时/导航重置、无效人格拒绝、刷新恢复、真实人格隔离、请求乱序与失败恢复。
- 16人格分别验证推荐排序，正式模式仍使用历史反馈。
- 相关回归：90 项通过，18 项真实试穿相关测试未纳入本次本地回归。
- 实际浏览器验证 NOIR / MELT 推荐变化，原 VOID 报告保留。

仅本地实现，未部署到生产服务器。
