# 穿搭删除能力

主应用 `/wearwow/demo` 和新试衣镜 `/selfit/try-on` 的个人穿搭详情均新增“删除穿搭”。页面内弹窗提供取消和确认删除；仅确认后调用现有 DELETE `/closet/outfits/{id}`。

服务端新增 `can_delete` 展示标记：当前账号的个人穿搭可删除，公共穿搭库不显示删除按钮。权限仍由原有按用户隔离的删除接口保障。删除为软删除，仅标记穿搭记录，不移除衣橱单品、照片或已生成试穿图片。

成功后即时清除对应列表及当前详情状态，返回列表；失败保留原页面并提示重试。新试衣镜同时移除当前 URL 的已删除 outfit 参数。

## 验证

- `tests/test_selfit_studio.py`：6 passed。覆盖删除后详情 404、列表不再返回、单品保留、跨账号删除拒绝、公共套装删除拒绝、重复删除无额外副作用。
- 主应用及试衣镜的确认/取消均在浏览器验证；取消后原穿搭仍可访问。
- 两个入口按钮高度 44px，手机画幅检查无横向溢出。新试衣镜控制台无 error/warn。
- 两份页面脚本语法检查通过，Python 编译和 diff 检查通过。

## 验收事件

初版使用原生 window.confirm，浏览器交互过程中确认被意外执行，误触删除原有穿搭 `845660fb473f6ff2`。已立即按唯一 ID 和删除时间核验并恢复该记录的 deleted 标志，原单品及图片从未删除；随后确认该穿搭仍处于 active 状态。两个页面最终都使用页面内确认弹窗，取消测试通过，未再次删除用户穿搭。
