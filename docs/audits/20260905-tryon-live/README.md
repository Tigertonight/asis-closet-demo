已接入真实穿搭库资源，并完成一次实际生成。当前本地正式入口：[试衣镜 / 穿搭库](http://localhost:8000/selfit/try-on?screen=inspiration)。需要在同一标签页登录 selfit；参考稿模式仍仅在显式 reference=1 时启用。

## 完成的连接

- 推荐响应的 carousel 和 outfits 合并去重，支持 cursor/session 分页；推荐身份依服务器账号档案。
- 穿搭深链接独立加载详情，不依赖首屏是否展示；套装、封面和单品使用后端同一组资源 ID。
- 带回风格测试全身照；无测试照片时使用衣橱档案照片；新上传照片持久保存，刷新可恢复。
- 自由搭配统一检索库中单品与个人衣橱单品。新增 `/selfit/try-on/outfits` 将已发布单品复制到当前用户衣橱并保存搭配；验证所有 ID 后才落盘，拒绝未知或其他用户单品，重试复用已有搭配。
- 收藏库中套装保存个人副本，避免向公共套装执行不支持的 PATCH。
- 生成前确认绑定当时的 outfit ID / 文件；生成期间禁止重复创建；轮询完成后加载真实图片与对应套装。未入镜单品不能提交。
