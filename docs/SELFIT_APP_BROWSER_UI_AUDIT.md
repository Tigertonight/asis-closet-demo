# selfit App 浏览器设计走查

日期：2026-08-31  
范围：`/wearwow/demo` 内全部主页面、关键弹层与核心状态  
基准：`DESIGN.md`，393 × 852px 移动端画布

## 已确认并修复

- 首页：移除不成立的“尚未完成风格测试”常驻卡片；App 只承接已完成 onboarding 的用户。
- 登录衔接：未登录进入统一 onboarding 登录；登录后继续 onboarding，不再绕过风格报告。
- 衣橱：将遮挡卡片的悬浮“开始搭配”改为头部紧凑入口。
- 衣橱：扩大单品主体在图片框中的视觉占比，降低空白感。
- 搭配选择：列表改为独立滚动区，`保存套装 / 生成试穿图` 固定在弹层底部。
- 搭配选择：统一卡片图片高度和双行标题，修复底部单品名称被裁切。
- 穿搭详情：增加内容底部安全距离，并将 CTA 改为完整底部操作坞，避免覆盖单品卡片。
- 调整搭配：重新标定默认单品尺寸与位置，让画布更接近可判断的 flat-lay，而不是散落的小缩略图。
- 我的：修复“试穿记录”选中态继承旧黑色底边造成的错位。
- 模特选择：修复“我的照片”状态下禁用确认按钮被网格拉伸的问题，并恢复品牌色虚线上传区。
- 色彩入口：从旧 `/demo` 改为 App 内 `page-color`，避免跳入遗留视觉系统。
- 色彩测试：恢复暖白底与品牌色虚线的自拍上传区。
- 通用弹层：增加背景遮罩，强化模态层级。
- 试穿：生成中隐藏结果操作按钮，移除与加载卡片重复的 Toast；“取消”现在会终止前端请求并回到可重试状态。

## 浏览器覆盖结果

- 推荐：首页首屏、今日推荐轮播、推荐流和长内容滚动。
- 问搭配：空状态、历史会话侧栏、会话右键菜单、删除确认弹层。
- 衣橱：单品、套装、分类横滑、搭配选择器。
- 详情 / 调整搭配 / 试穿：详情、编辑画布、生成加载、取消、成功结果和重新生成入口。
- 我的：试穿记录、我的作品（套装 / 单品）、我的收藏、预设模特与本人照片上传状态。
- 添加衣服：相册 / 拍照 / 链接提取入口与弹层层级。
- 色彩测试：App 内上传初始态。
- 图片查看：单品图片灯箱、适应屏幕与关闭操作。

## 尚需真实素材或服务返回才能覆盖的状态

- 衣服相册上传、相机权限和链接提取的成功 / 失败结果。
- 色彩测试分析结果与服务错误状态。
- 问搭配的完整流式回答卡片。

这些状态共用的页面骨架与入口已经检查；继续验证需要提交真实图片、外部链接或触发模型服务，不属于纯页面遍历。
