- 发布不再要求靠凑数维持 1,200：至少每人格 10 套可推荐内容；不足时继续回退。就绪检查按源文件和精修版本缓存，避免每次重复解析大型清单。

## 文件与复现

- 策略与实际数据补丁：`app/static/selfit/data/content-curation.v1.json`
- 运行时质量层：`app/selfit_content_quality.py`
- 生成精修层：`.venv/bin/python scripts/curate_selfit_content.py`
- 数量、待复核 ID 与下一批队列：`docs/SELFIT_CONTENT_CURATION_STATUS.json`
- 验证：`.venv/bin/pytest tests/test_selfit_content_quality.py tests/test_selfit_content_expansion.py tests/test_selfit_content_v2.py tests/test_selfit_recommend.py tests/test_closet.py -q`

精修生成器先校验原池与审查报告的 SHA-256；源版本改变时停止，避免旧结论误作用于新内容。读入精修数据损坏或新版本未经复核时，生成式新内容不自动放行。
