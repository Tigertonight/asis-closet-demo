# 推荐来源与统一封面（2026-09-03）

- 正式模式：旧 Demo `w_outfit_*` 不再因同步到用户衣橱而获得个人搭配优先名额；真正自建搭配保留原有展示机会。未删除 Demo 或用户资产。
- 测试模式：仅查询已发布、审核可用且 `primary_persona` 对应所选人格的内容池。不读取私人搭配或行为反馈，也不在空池时回填 Demo / 参考照片。
- 普通款、连衣裙和叠穿统一由 `app/outfit_layout.py` 定义 1200×1500 画布、暖白背景、透明边缘裁切、腰线间隔和右侧配件区。叠穿仍保留外套与内搭独立区域。
- 首页、衣橱、预览使用 contain；列表固定 4:5，图片以绝对定位获得确定高度，移除 1.06 放大。试穿结果照片的展示规则不变。
- 离线运行 `.venv/bin/python scripts/build_selfit_outfit_previews.py` 可生成/续建全部封面。1,200 配方对应 1,187 个唯一单品组合，因此共享 1,187 张派生封面。重复配方未篡改或重新发布。
- 派生资产位于 `app/static/selfit/assets/content_v2/layouts/unified-flatlay-v1/`，每张附位置 QA。原始发布清单和原图不变；已有 hold / alias 审核隔离仍生效。若派生图缺失，回退原始图片而非白屏。
- 私人衣橱使用同一排版规则，但图片仍写入用户自己的目录；旧封面保留，迁移结果按现有清单缓存，不公开私人照片。

验证覆盖：16 人格隔离、旧 Demo 不占优先名额、空池无混入、普通/裙装/叠穿共用规则、全部配方单品各一次、安全留白、无重叠、源清单保持不变，以及浏览器移动端/桌面完整展示。

这是本地实现和验证，不代表已经部署到线上服务器。
