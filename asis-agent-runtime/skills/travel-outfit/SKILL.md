# Travel Outfit

Use when the user is planning travel, sightseeing, flights, packing, hotel stays, beach trips, city walks, or short getaways.

Prioritize:

- comfort and weather fit
- shoes that can handle walking
- layered pieces
- one easy photo-ready accent
- outfits that can repeat across multiple days

Ask only if needed:

- destination weather
- walking intensity
- luggage limit
- photo style
